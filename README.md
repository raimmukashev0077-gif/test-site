# FORMA — магазин аксессуаров для телефона

Минималистичная витрина с корзиной и оплатой картой через Stripe Checkout
(Visa, Mastercard, Apple Pay, Google Pay). Никаких сборщиков и зависимостей.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка страницы |
| `styles.css` | Дизайн |
| `products.js` | **Каталог: товары, цены, цвета, валюта, доставка** — редактируйте здесь |
| `art.js` | SVG-иллюстрации товаров |
| `app.js` | Логика: фильтры, карточка товара, корзина, переход к оплате |
| `api/checkout.js` | Серверная функция Vercel, создаёт платёж в Stripe |

## Запуск оплаты

1. Зарегистрируйтесь на stripe.com и возьмите **тестовый** секретный ключ (`sk_test_...`)
   в Developers → API keys.
2. Опубликуйте папку на Vercel и добавьте переменную окружения
   `STRIPE_SECRET_KEY` (Project → Settings → Environment Variables), затем сделайте Redeploy.
3. Проверьте оплату тестовой картой `4242 4242 4242 4242`, любой будущий срок, любой CVC.
4. Для реальных платежей активируйте аккаунт Stripe и замените ключ на `sk_live_...`.

Цены считаются на сервере по `products.js`, поэтому подменить их из браузера нельзя.
Если открыть `index.html` просто как файл, всё работает, кроме кнопки оплаты.

## Свой дизайн чехла (студия)

Покупатели собирают дизайн (цвет, узор, своя картинка, надпись) и отправляют его.
Дизайны хранятся в Supabase, в галерею попадают только одобренные.

1. В Supabase откройте SQL Editor и выполните `supabase/schema.sql`.
2. В Vercel добавьте переменные `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`
   (Supabase → Project Settings → API). Секретный ключ хранится только на сервере.
3. Новые дизайны приходят со статусом `pending`. Чтобы показать дизайн в галерее,
   поменяйте статус на `approved` в Table Editor → `case_designs`.
